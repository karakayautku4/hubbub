Welcome to Hubbub

Install

  1. Drag Hubbub onto the Applications folder in this window.
  2. Open Applications and double-click Hubbub. A small icon appears in the menu bar (top right of your screen). There is no Dock icon.

If macOS says it can’t verify the app

Hubbub is signed and notarized by Apple, so you normally will not see this. If macOS still blocks it, use one of these (once only).

Option 1 – right-click: in Applications, right-click (or Control-click) Hubbub → Open → Open.

Option 2 – System Settings: try to open Hubbub once, then go to System Settings → Privacy & Security, scroll down to the message about “Hubbub” and click Open Anyway. Confirm with your password.

Option 3 – Terminal (advanced):
xattr -dr com.apple.quarantine /Applications/Hubbub.app

Uninstall

Quit Hubbub from its menu and drag it from Applications to the Trash.
