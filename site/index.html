FAQ

Does it send my code or prompts anywhere?

No. Hubbub only reads local session logs and shows tool names, timestamps and token counts.

Do I need a GitHub token?

Only for the Copilot quota bar (via gh auth login). Everything else works without it.

Which macOS versions are supported?

macOS 14 (Sonoma) or later, on Apple silicon and Intel.

Can I add my own theme or provider?

Yes. See the theme guide and contributing.

Is it affiliated with GitHub, Anthropic, OpenAI…?

No. Hubbub is an independent project. Names and logos belong to their owners.
